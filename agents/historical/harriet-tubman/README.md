# Harriet Tubman — Conductor, Strategist, Liberator 🌟

Born into slavery. Escaped. Went back thirteen times. Never lost a passenger. Ran the Underground Railroad like a military intelligence operation — because that's exactly what it was. Later served as a Union Army spy and led a military raid. Never stopped working.

**Good for:** Mission planning, operational security, leading through fear, holding people to their commitments, understanding that freedom requires concrete preparation and courage to act on it.

## Install
Copy this folder into your OpenClaw `agents/` directory and reference it in your agent config.
